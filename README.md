# garmin-insert
bulk-inserts a garmin device into FIT files so that Garmin Connect computes some training related quantities

Vibe coded using Google Gemini

The code was used to fix cycling .fit files generated by the Wahoo app.
Even though the files do contain power and heart rate data, Garmin Connect refused to use
this information to compute training load and other quantities. Inserting a Garmin device code
into the .fit files fixes that, and at least some of the missing quantities get computed.  
(Training Effect seems to be still missing, but VO2max, Exercise Load and Training Load are there now.)

I decided to document the code on Github, since it might be useful for other people running into the same problem.
In principle, fit-file-faker should do the same job, but despite Gemini's and my best efforts it did not work 
for my Wahoo app files.
